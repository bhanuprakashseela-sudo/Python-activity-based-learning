## Introduction

This repository contains ten beginner-friendly Python case studies. The
programs practise fundamental programming concepts such as variables,
input and output, operators, conditional statements, loops, strings,
lists, and basic calculations.

## Case Studies

### Case Study 1: University Scholarship Allocation

Evaluates students for scholarship eligibility using marks, attendance,
and family-income conditions. It calculates average marks and displays
whether each applicant qualifies.

### Case Study 12: Attendance Recovery Computation

Calculates how many additional consecutive classes a student must attend
to reach a required attendance percentage.

### Case Study 13: ATM Transaction Sequence Simulation

Simulates deposits and withdrawals, updates the account balance, checks
transaction amounts, and rejects withdrawals that exceed the available
balance or transaction limit.

### Case Study 15: Smart Parking Fee Management

Calculates parking fees based on vehicle type and parking duration,
rounds partial hours up to a full hour, and applies a maximum fee.

### Case Study 17: Student Performance Trend Analysis

Stores marks from multiple examinations, calculates the average,
compares consecutive exam results, and classifies the latest
performance.

### Case Study 18: Fuel Consumption and Route Comparison

Calculates fuel requirements and estimated journey costs using distance,
vehicle mileage, reserve fuel, and fuel price. It identifies the
lowest-cost valid vehicle option.

### Case Study 19: Multi-Product Shopping Budget Constraint

Calculates product subtotals and the total shopping cost, then checks
whether the purchase is within the available budget.

### Case Study 27: Advanced Numeric Pattern Generator

Uses nested loops to print a symmetric numeric pattern and checks that
the requested row count is positive.

### Case Study 29: Password Policy Validation Engine

Checks a password for minimum length and the presence of uppercase
letters, lowercase letters, and digits. It reports any missing
requirements.

### Case Study 39: Multi-Stage Examination Eligibility System

Checks examination eligibility using attendance, lab completion,
internal marks, and fee-payment status, and reports any unmet
requirements.

## How to Run a Program

1.  Install Python 3 from [python.org](https://www.python.org/) if it is
    not already installed.

2.  Download or clone this repository.

3.  Open a terminal or command prompt in the project folder.

4.  Run the required program, for example:

    ``` bash
    python case_study_01_university_scholarship.py
    ```

5.  Enter the values requested by the program and read the output.

Replace the example filename with the program you want to run.
